# マドプレ (Mansion Layout PWA)
> **マンションの図面から手持ち家具の配置シミュレーションができるPWA**

買い替えに伴う複数物件の比較時、手持ちの家具がどう収まるかを現地や移動中にすぐ確認できるモバイルファーストのWebアプリケーションです。

---

## 🌟 実装機能一覧

| 大項目 | 詳細機能 | 対応モジュール |
| :--- | :--- | :--- |
| **1. 図面入力** | スマホの写真ライブラリ・ファイル選択、カメラ直接撮影、サンプル図面 | [`index.html`](./index.html), [`js/sample-data.js`](./js/sample-data.js) |
| **2. パース歪み補正** | 4隅指定によるホモグラフィ透視投影変換（三角形メッシュ変形） | [`js/math/perspective.js`](./js/math/perspective.js) |
| **3. 広さ推定・スケール** | 任意の1箇所（ドア幅80cm等）の実寸指定からpx/cm縮尺とグリッド自動計算 | [`js/app.js`](./js/app.js), [`js/canvas/renderer.js`](./js/canvas/renderer.js) |
| **4. 属性設定** | 開き戸（90°開閉扇形軌道、吊元反転）、窓のタップ＆ドラッグ配置 | [`js/canvas/renderer.js`](./js/canvas/renderer.js), [`js/canvas/interaction.js`](./js/canvas/interaction.js) |
| **5. 家具入力** | 豊富な標準プリセット（ベッド、ソファ、デスク等）＋カスタム手持ち家具登録 | [`js/models/project.js`](./js/models/project.js) |
| **6. 配置 & 干渉判定** | ドラッグ＆ドロップ、90°回転、壁境界制限、ドア軌道干渉警告、窓重複警告 | [`js/math/collision.js`](./js/math/collision.js) (SAT & 扇形交差判定) |
| **7. データ保存・比較** | 複数物件のローカル保存、1物件内での「案1 / 案2」の複製・切替・画像保存 | [`js/models/project.js`](./js/models/project.js), LocalStorage |
| **8. 免責事項・PWA** | 現地実測推奨の免責事項常時明示、オフラインService Worker、Manifest | [`manifest.json`](./manifest.json), [`sw.js`](./sw.js) |

### 💻 ローカル環境での実行

#### 1. サーバーの起動
プロジェクトディレクトリにて以下のいずれかを実行します：
```bash
# Node.js を使用する場合
node server.js

# または Python を使用する場合
python3 -m http.server 8080
```

#### 2. ブラウザでアクセス
- **PCブラウザ**: `http://localhost:8080`
- **同一Wi-Fi内のスマートフォン**: `http://<PCのローカルIPアドレス>:8080`
  - *(MacのローカルIPの確認コマンド: `ipconfig getifaddr en0`)*

## 💡 操作手順ガイド

1. **家具のシミュレーション**:
   - 図面上の家具をタップすると青い枠が表示され、ドラッグで移動、上の丸いハンドルまたは「↻ 90°回転」で回転できます。
   - **ドアの近くに家具を移動すると「⛔ ドア開閉に干渉しています」と警告が出ます。**
   - **窓の近くに家具を移動すると「⚠️ 窓が隠れます」と警告が出ます。**
2. **手持ち家具の追加**:
   - シート内の「＋ 手持ち家具を登録」から、縦横の寸法（cm）とカラーを指定してワンタップで配置できます。
3. **案の比較**:
   - 上部の「案1 / 案2」タブで配置パターンを切り替えたり、「＋ 案追加」「📋 複製」で手軽に別パターンを比較検討できます。
4. **自身の図面の取り込み**:
   - 「① 図面取込」からスマホで撮影したチラシ図面や写真ライブラリの画像を選択します。
   - 「② パース補正」で四隅ピンを合わせれば、斜め撮影の写真も自動で真っ直ぐな平面図へ補正されます。
   - 「③ スケール設定」でドア幅などの実寸を入力すれば、手持ちの家具との縮尺が完全に一致します。
